# PLCSIM.UnitTest 2.0.0

Release notes for the 2.0.0 Windows distribution.

## What Changed

This version replaces the legacy application/plugin layout with a shared workflow
for the WPF desktop application and CLI, plus independently packaged access profiles.

- **Desktop testing and diagnostics:** session configuration, repeated test runs,
  result inspection and retained evidence for run, lifecycle and communication analysis.
- **CLI automation:** project preparation, transfer and test execution with defined
  exit codes, JUnit XML and adaptable CI starters for GitLab CI, GitHub Actions,
  Jenkins, Azure Pipelines and TeamCity.
- **Access profiles:** vendor engineering/runtime integration stays behind shared
  contracts. Siemens composes TIA Openness and PLCSIM Advanced bindings; Beckhoff
  supplies a TwinCAT 4026 profile for an existing local Usermode Runtime.
- **Distribution:** component ZIPs with integrity manifests and license notices,
  an exact hash-pinned bundle and an offline Windows installer.
- **Public source builds:** shared scripts under `tools/`, local package resolution
  and reproducible canonical contracts with normalized Release source paths.

## Requirements And Installation

- Windows x64, .NET 8 Desktop Runtime x64 and .NET Framework 4.8.
- Separately installed vendor engineering/runtime products, licenses and access
  authorization required by the selected profiles and bindings.
- A PLC test project using the matching PLC UnitTest framework. These frameworks
  are separate projects; see [current targets and companion frameworks](../../README.md#current-plc-targets).

The installer does not download host runtimes or vendor prerequisites. See the
[technical requirements](../project-specification.md) and
[installation and maintenance guide](../deployment/windows-installation.md).

The installer is unsigned. Compare its SHA-256 against `SHA256SUMS` and keep the
matching `bundle-manifest.json`; checksums establish integrity, not publisher identity.

## Verification And Provenance

The component packages were built from public source commit
`75ff10ee14b66b49be15734c56c2ac49eb93845e` using the clean-source release workflow.
Every package manifest records that revision. The
[bundle definition](../../distribution/bundles/installer-2.0.0.json) pins the exact
manifest hashes; later bundle/release-note metadata does not change that component
source identity.

- All twelve package builds and their dependency/license checks passed.
- The deterministic test matrix passed: 3,160 tests across 19 suites, with
  live-runtime test classes excluded. Subsequent PLCSIM Advanced test-worker
  deployment and path-resolution corrections passed all 621 affected tests in
  both Debug and Release. These test-only changes do not affect the packaged
  application or workers.
- Contract verification passed; independent-directory reproduction of all six
  canonical DLL/PDB files was previously verified with the same Windows toolchain.
- Full bundle resolution, distribution staging, installer compilation and Windows
  release verification passed, including isolated profile registration.

Live PLC/runtime tests, interactive WPF startup and installer
install/upgrade/uninstall are outside this public packaging verification. Historical
profile qualification evidence remains in the profile-owned documentation.
