# PLCSIM.UnitTest Windows Distribution 2.0.1

This patch corrects Siemens PLCSIM Advanced event-buffer consumption. The
application remains version 2.0.0; the Windows distribution and PLCSIM Advanced
V6/V7/V8 bindings and workers advance to 2.0.1.

## What Changed

PLCSIM Advanced V6/V7/V8 now read FIFO positions from `Index_OUT` up to, but
excluding, `Index_IN`, including when `BufferFull` is set. The next producer
write slot remains outside the readable range. A full FIFO contains
`BufferLength - 1` readable entries; the configured batch limit still applies.
Batch publication and release ordering are unchanged.

Regression tests cover full and wrapped FIFO ranges, batch limits, unused-slot
contents, invalid metadata and capacity boundaries. The
[PLC-owned contract reference](../references/s7unittest/contracts/event-stream-model-contract.md)
has been refreshed to the recorded clarification. This PC-side fix requires
no PLC project download or shared API migration. Application behavior and
shared APIs are unchanged.

## Requirements And Installation

Host and vendor prerequisites remain unchanged: Windows x64, .NET 8 Desktop
Runtime x64, .NET Framework 4.8, and the engineering/runtime products and
authorization required by the selected profile. Use the Windows installer and
refresh profile registrations if requested. See the
[installation and maintenance guide](../deployment/windows-installation.md)
and the owning [Siemens](../../access-profiles/siemens/README.md) and
[Beckhoff](../../access-profiles/beckhoff-tc3-4026/README.md) documentation.

The installer is unsigned. Compare its SHA-256 against `SHA256SUMS` and retain
the matching `bundle-manifest.json`. Checksums establish integrity, not publisher
identity.

## Artifact Provenance

The installer, `bundle-manifest.json` and `SHA256SUMS` are the original release
files, retained without rebuilding or modifying their bytes. The
[2.0.1 bundle definition](../../distribution/bundles/installer-2.0.1.json)
matches the release bundle byte-for-byte and pins the exact package manifests.

Release source identities:

- Distribution snapshot: `62e50fcb05ec326ca6b3c591ee8d07c1e59234ab`.
- PLCSIM Advanced V6/V7/V8 binding packages: `b3a7275903b51a4aea5c13ebc04fe09be56b560d`.

The other nine component packages reuse the original development release's
2.0.0 distribution inventory, retaining their own versions and source revisions.
Their manifest pins differ from those in the previous public
[2.0.0 bundle](../../distribution/bundles/installer-2.0.0.json). Reuse refers to
that original inventory; byte identity with the previous GitHub 2.0.0 packages
has not been established.

The public repository selectively integrates the release source while retaining
its public build tooling and canonical contract binaries. The supplied artifacts
were built from the source revisions recorded by their package manifests; they
are not builds of the public integration commit. Public source builds produce
separate outputs and must not replace these release files under the same version.
