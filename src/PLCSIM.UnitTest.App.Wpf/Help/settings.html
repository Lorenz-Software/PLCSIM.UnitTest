Settings scope

Open Tools > Settings... to configure application-level defaults and file/logging policy. Settings initialize new sessions; they do not replace the selected profile's configuration or the current session choices.

General

SettingDescription
Build and download project by defaultInitializes the Step 1 project-handling choice for new manual sessions and imported drafts. The checkbox remains editable. Load UnitTest always uses application-managed project handling.

Timeouts

Values are entered in seconds and define application-owned overall operation or observation boundaries. Imported configuration and current-session overrides take precedence where supported.

Setup

SettingDescription
Project prepareLimits opening or refreshing the selected project and preparing its target context.
Build and transferLimits the combined project build and download operation.
Runtime prepareLimits preparation of the selected or newly created runtime target.
Communication prepareLimits establishment of UnitTest communication after the PLC becomes usable.

PLC control

SettingDescription
PLC commandLimits the API call used to submit a PLC start or stop command.
PLC start reactionLimits monitoring for an observed PLC state compatible with a successful start request.
PLC stop reactionLimits monitoring for an observed PLC state compatible with a successful stop request.

UnitTest execution

SettingDescription
UnitTest commandLimits submission of a Start, Abort, or Reset command to the PLC-side UnitTest application.
UnitTest reactionLimits monitoring for evidence that the PLC-side application reacted to the submitted command.
Test runLimits observation of an active RunControl epoch until completion.
Final event evidenceLimits the final wait for result and aggregation events after completion has been observed.

Recovery

SettingDescription
Communication revalidationLimits how long stale UnitTest communication may recover before it becomes invalid. A value of zero disables this terminal timeout.

Files and logging

Output

SettingDescription
Output directoryDefines the base directory for generated test-result artifacts. The default is %LOCALAPPDATA%\PLCSIM.UnitTest\artifacts. The resolved path is shown below the editor.
Test result file nameDefines the file name used for the generated JUnit XML artifact.

Logging

SettingDescription
Log directoryDefines the directory containing application, access-profile, and worker logs. The resolved path is shown below the editor.
Retention daysDefines how long eligible log files are retained.
Application log levelControls diagnostic detail emitted by the WPF application and shared application services.
Access profile log levelControls diagnostic detail emitted by access profiles. Their internal workers inherit this level unless another host explicitly overrides it.
Log raw access-profile eventsAdds raw event evidence for focused troubleshooting. The option is available only when the access-profile log level is Debug.
Restart boundary. Logging-path and logging-policy changes apply on the next application start. Commands opening the current log continue to target the active startup log.
